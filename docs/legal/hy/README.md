# Արհեստավորի իրավական փաստաթղթային բազա

*Թարգմանություն 2026 թ. ֆրանսերեն տարբերակից (ֆրանսերեն սկզբնաղբյուրը ամսաթիվ չի նշում)։ Վավերական է ֆրանսերեն տարբերակը։ Պաշտոնական տեքստերը մեջբերված են ֆրանսերենով։*

Տեքստեր և հղումներ, որոնց վրա հիմնված են Crénelio-ի *devis*-ները (նախահաշիվները) (Item 22)։ Սա Item 40-ի
փաստաթղթային բազայի առաջին ձևն է՝ Markdown ֆայլեր, յուրաքանչյուր լեզվի համար մեկ թղթապանակ (`fr/`-ն է
վավերական)։ Հետագայում դրանք կբեռնվեն տվյալների բազա և կթարգմանվեն. պաշտոնական տեքստերի հատվածներն այդ
դեպքում մնում են ֆրանսերենով՝ թարգմանված բացատրությամբ։

Այս տեղեկանքները կարելի է կարդալ նաև Արհեստավորի տարածքում (մենյու **Aide › Documentation** (Օգնություն ›
Փաստաթղթեր))։ Այստեղ ավելացված յուրաքանչյուր տեղեկանք հայտնվում է այնտեղ, տեղեկանքների միջև հղումները
մնում են հարաբերական։

## Թարգմանություններ

`en/`, `es/`, `pt/`, `hy/`, `it/`, `de/`, `pl/`, `uk/`, `ru/`, `gcf-gp/`, `gcf-mq/`, `tr/`, `ar/`, `ro/` և, զվարճանքի համար, `fr-chti/` (շ'տի) (05/11/2026) թղթապանակները պարունակում են `fr/`-ի տեղեկանքները նույն անվամբ, իսկ `README.md`-ն՝
բովանդակությունը։ Պաշտոնական տեքստերը (`fr/textes/`) և `sources.md`-ն չեն թարգմանվում. դրանք
մեջբերվում են ֆրանսերենով։ **Վավերական է ֆրանսերեն տարբերակը**. ֆրանսերեն տեղեկանքի յուրաքանչյուր փոփոխություն
փոխանցվում է դրա թարգմանություններին (կամ դրանք նշվում են որպես հնացած)։ Արաբերենը (`ar/`) գրվում է աջից ձախ. դրա պաշտոնական մեջբերումները, ֆրանսերենով, շարունակում են ցուցադրվել ձախից աջ։

## Կանոններ

- Յուրաքանչյուր ֆայլ նշում է իր **աղբյուրները** (հղում) և **վերջին ստուգման ամսաթիվը**։
- Պաշտոնական տեքստերի հատվածները (Légifrance, վարչակազմի տեղեկանքներ) վերարտադրվում են անփոփոխ՝
  չակերտներում կամ մեջբերման տեսքով. մասնավոր աղբյուրները (ուղեցույցներ, մասնագիտացված կայքեր)
  **ամփոփվում են**, երբեք չեն պատճենվում։
- Մեջբերված պաշտոնական տեքստի ներկայացումը (ինչպես Légifrance-ում)՝ `### Article …` վերնագիր, ապա
  `>` մեջբերում, որում **յուրաքանչյուր պարբերություն (*alinéa*) առանձին պարագրաֆ է** (ներառյալ « 1° », « a) », « II. - » թվարկումները,
  բաժանված դատարկ `>` տողով). տարբերակի նշումը (« Modifié par… », « Création… ») առաջին
  պարբերությունն է, ապա « NOTA : »-ն՝ առանձին տողում։ Documentation էկրանը դրանից է ստանում ձևավորումը. տեքստն
  ինքնին երբեք չի փոփոխվում։
- Երկրորդական աղբյուրը չի փոխարինում պաշտոնական տեքստին. այն նշվում է որպես այդպիսին և ծառայում է միայն
  ճիշտ տեքստը գտնելուն։ **Crénelio-ում կիրառվող յուրաքանչյուր կանոն պետք է հաստատված լինի պաշտոնական
  տեքստով**՝ երրորդ անձանց (գրասենյակներ, հրատարակիչներ, բլոգներ) մեկնաբանության աղավաղումներից
  խուսափելու համար։
- Յուրաքանչյուր կարգավորիչ փոփոխության դեպքում (Item 39)՝ թարմացնել ֆայլը, դրա ամսաթիվը և համապատասխան
  կոդը (`api/models/Quote.php`, `quote_*` / `legal_*` կարգավորումներ)։
- Այս տեղեկանքները օգնություն են, ոչ թե իրավաբանական խորհրդատվություն. կասկածի դեպքում արհեստավորը դիմում
  է իր հաշվապահ-փորձագետին (*expert-comptable*) կամ արհեստների պալատին (*chambre de métiers*)։
